# Trades Aptitude Practice

Practice site for Chicago-area skilled-trades apprenticeship aptitude tests
(Cook and DuPage counties).

**Unofficial practice material, not affiliated with any union, JATC, or test
publisher.**

Status: Phase 0 (inventory and plan). See `PLAN.md` for the live checklist,
`docs/blueprints/` for per-trade test formats and their confidence labels,
and `docs/CORRECTIONS.md` for every content change and conflict found.

Build, verification and deploy instructions land here in Phase 1.
