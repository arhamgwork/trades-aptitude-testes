# ANSWER KEY

## Section 1 — Algebra & Functions

**1. B — 1.** 7 + 3(4 − 6) = 7 + 3(−2) = 7 − 6 = 1. Do the parentheses first; the negative inside is the whole trap.

**2. C — 5.** 9x − 4x = 18 + 7 → 5x = 25 → x = 5.

**3. B — 16.** (35 − 3)/2 = 32/2 = 16.

**4. B — 5.** 6x − 12 + 4 = 2x + 12 → 6x − 8 = 2x + 12 → 4x = 20 → x = 5.

**5. A — b = 2A/h − a.** Multiply both sides by 2: 2A = h(a + b). Divide by h: 2A/h = a + b. Subtract a.

**6. B — 10.** 48 = 2(14) + 2W → 48 = 28 + 2W → 2W = 20 → W = 10.

**7. B — 13.** −3² = −9 (the exponent binds tighter than the negative sign — this is the #1 missed detail). (−4)² = +16. −2(5 − 8) = −2(−3) = +6. So −9 + 16 + 6 = 13.

**8. C — 16.** (3/4)x = 12 → x = 12 × 4/3 = 16.

**9. B — 25.** 77 − 32 = 45. 45 = (9/5)C → C = 45 × 5/9 = 25.

**10. A — a = 2d/t².** Multiply by 2, divide by t².

**11. C — 43.** 4(−2)² = 16. −3(−2)(3) = +18. (3)² = 9. Total 16 + 18 + 9 = 43. Two negatives multiplied make the middle term positive.

**12. C — 96.** Doubling each time.

**13. C — 117.** Alternating +3, −6. After 114 comes +3 → 117.

**14. B — 42.** Alternating ×2, −2. After 44 comes −2 → 42.

**15. D — 95.** ×2 + 1 each time. 47 × 2 + 1 = 95.

**16. C — 16.** Two interleaved series: 1, 2, 3, 4 and 4, 8, 12, **16**.

**17. C — 27.** Alternating ÷2, ×1.5. 18 × 1.5 = 27.

**18. A — 4x² − 8x − 60.** FOIL first: (x + 3)(x − 5) = x² − 2x − 15. Then multiply everything by 4. Distributing the 4 to only one term is the trap in choice B and D.

**19. B — (x + 7)(x − 7).** Difference of squares.

**20. B — 3x(x + 4).** A and C are valid factorings but not *complete* — the question says completely, so you must pull out both the 3 and the x.

**21. A — 4x² − 9.** Difference-of-squares pattern; the middle terms cancel.

**22. A — (x − 5)(x + 4).** Need a product of −20 and a sum of −1: that's −5 and +4.

**23. B — y = 3x − 2.** y goes up by 3 each time x goes up by 1, so the slope is 3. Test x = 1: 3 − 2 = 1. ✓

**24. A — (0, −6).** The y-intercept is the constant in y = mx + b. Choice B is the *x*-intercept — read the question.

**25. B — 1.** (6 − (−2)) / (5 − (−3)) = 8/8 = 1.

**26. C — 2.** 16 − 20 + 6 = 2.

**27. B.** Find where a = 0: (1/3)b = 6 → b = 18. Below 18, a is negative; above 18, positive. Only B holds for every value in its stated range. (Choice C fails at b = 3: a = −5.)

**28. A.** m = 0 at n = 3. Above 3, you're subtracting more than 12, so m goes negative. C fails at n = 5 (m = −8); D fails at n = −1 (m = 16).

**29. A.** y = 0 at x = −4. Anything greater than −4 gives positive y. B fails at x = −1 (y = 6).

**30. B — halved.** P on top doubles W (×2). V on the bottom is squared, so doubling V multiplies the denominator by 4 (÷4). Net: ×2 ÷ 4 = ½. **The squared variable is where people lose this one.**

**31. B — 144 ft.** (3 × 62) + (2 × 85) = 186 + 170 = 356. 500 − 356 = 144.

**32. B — $7,946.40.** 8,600 × 0.88 = 7,568. Then 7,568 × 1.05 = 7,568 + 378.40 = 7,946.40. You cannot combine −12% and +5% into −7% — that's what choice C is fishing for.

**33. B — 41 ft.** x + (x + 12) = 94 → 2x = 82 → x = 41. (Shorter run; the longer is 53, which is choice D — read which one they want.)

**R1. D — 95.** ×2 + 1.

## Section 4 — Problem Solving

**P1. B — 17 ft.** 8² + 15² = 64 + 225 = 289; √289 = 17. (8-15-17 is a Pythagorean triple worth memorizing alongside 3-4-5 and 5-12-13.)
**P2. B — 54.** Room area 432 sq ft ÷ 8 sq ft per panel = 54.
**P3. C — 15 days.** 5 × 12 = 60 worker-days. 60 ÷ 4 = 15. Fewer workers = more days (inverse).
**P4. C — $525.00.** 1,250 × 0.42.
**P5. B — 4.** 10 ft ÷ 2.5 ft = 4 exactly.
**P6. C — 432 mi.** 18 × 24.
**P7. B — 30 min.** 480 ÷ 16.
**P8. C — 28 ft.** ¼ in = 1 ft means 1 in = 4 ft. 7 × 4 = 28.
**P9. B — 18⅓ lb.** 55 ÷ 3.
**P10. C — 62.5%.** 5 of 8 unused = 0.625. The question asks for *unused* — 37.5% is the used figure and the trap.
**P11. C — 35.** 4,115 − 1,840 = 2,275. 2,275 ÷ 65 = 35.
**P12. B — 8.** 6:45 a.m. to 3:15 p.m. is 8½ hours; subtract the 30-minute unpaid lunch.
**P13. C — 13.5.** 189 ÷ 14.
**P14. B — 11.1.** 6 in = 0.5 ft. 30 × 20 × 0.5 = 300 cu ft. 300 ÷ 27 = 11.1 cu yd. **Remember: 27 cubic feet per cubic yard.**
**P15. B — 2 hr.** 1/6 + 1/3 = 1/6 + 2/6 = 3/6 = 1/2 of the tank per hour → 2 hours. Never average the times.
**P16. C — 50%.** Markup of $9 on a cost of $18.
**P17. C — 270.** 60 yd × 36 in = 2,160 in. 2,160 ÷ 8 = 270.
**P18. B — 25 ft.** 20² + 15² = 400 + 225 = 625; √625 = 25. (A 3-4-5 scaled by 5.)

## Section 5 — Mechanical Comprehension

**M1. D — 360 rpm.** Gears are inverse: 60/20 = 3, so triple the speed. Fewer teeth = faster.
**M2. B — opposite directions.** Directly meshed gears always counter-rotate.
**M3. B — 75 lb.** Load × load arm = effort × effort arm. 300 × 2 = 600. 600 ÷ 8 = 75.
**M4. C — 100 lb.** A fixed pulley changes the *direction* of your pull but gives no mechanical advantage.
**M5. B — 60 lb.** A movable pulley gives 2:1.
**M6. B — 100 lb.** Divide the load by the number of supporting rope sections: 400 ÷ 4.
**M7. B — more torque.** Torque = force × distance from the pivot.
**M8. B — faster.** Big driving small means the small one spins more times per revolution.
**M9. B — less force over more distance.** The trade-off built into every simple machine.
**M10. C — inclined plane.** A screw is a ramp wrapped around a cylinder.
**M11. B — 100 lb.** A uniform load split evenly between two equidistant supports.
**M12. C — 500 lb.** Area ratio 20:2 = 10:1. 50 × 10 = 500.
**M13. A — increases.** Pressure rises with depth.
**M14. B — harder to stop.** More mass, more momentum.
**M15. B — more force.** Large wheel to small axle multiplies force.
**M16. B — in the opposite direction.** That's the entire purpose of crossing a belt.
**M17. A — same direction as A.** A and B oppose, B and C oppose, so A and C match. Odd gear counts match; even counts oppose.
**M18. D — block and tackle with 4 supporting ropes.** Highest mechanical advantage of the four.
**M19. B — half the force.** Double the lever arm, half the force for the same torque.
**M20. B — more stable.** Wider base, lower tipping risk.

## Section 6 — Paper Folding

**F1. B — 2.** 1 fold = 2 layers.
**F2. C — 4.** 2 folds = 4 layers.
**F3. C — 8.** 3 folds = 8 layers.
**F4. C — 8.** 4 layers × 2 holes.
**F5. C — 6.** 2 layers × 3 holes.
**F6. C — 16.** 8 layers × 2 holes.
**F7. B — 2.** A diagonal fold still produces only 2 layers. The fold's *angle* doesn't change the layer count — only the number of folds does. This is the most common trap in the section.
**F8. C — 12.** 4 layers × 3 holes.
**F9. C — 16.** 4 folds = 16 layers.
**F10. B.** A fold creates mirror symmetry across the fold line. The fold was vertical, so the two holes mirror across the vertical center line, and both stay in the upper half because the punch was near the top.
**F11. B.** Two perpendicular folds create symmetry across both center lines, putting one hole in each quadrant, all equidistant from the center.
**F12. A — 1.** Punching only the top layer punches only one sheet. Layer count is irrelevant if the punch doesn't go through. **Read every one of these for whether the punch goes through all layers.**
